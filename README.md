An original Art-Deco Blueprint top-down heist game playable completely offline in a desktop browser (`node serve.ts`), featuring 4 multi-route vaults, raycast vision cones, sweeping CCTV cameras, costly gadgets (`EMP`, `Decoy`, `Smoke`, `Circuit Tap`), a fair 1.2s caught-grace recovery window, and procedural Web Audio.

Built for [make.fun](https://make.fun/bounty/best-heist-game-20261122-0559). Run: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
